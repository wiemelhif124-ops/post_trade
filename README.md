# Système GenAI Multi-Agents - Monitoring Post-Trade

Prototype d'un assistant conversationnel GenAI basé sur une architecture multi-agents pour l'analyse des opérations post-trade (Custody, Clearing & Settlement, Cash Management).

## Démarrage rapide

### Prérequis
- Docker Desktop installé et démarré.
- 8 Go de RAM minimum.

### Lancement en une commande
```bash
docker-compose up -d --build
